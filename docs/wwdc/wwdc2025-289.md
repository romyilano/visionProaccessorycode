## Overview

Learn how to create a spatial sculpting app for visionOS using new spatial accessory support. This session covers how to integrate PlayStation VR2 Sense controllers and Logitech Muse with your visionOS apps, providing finer control, button input, and haptic feedback.

---

## Introduction to Spatial Accessories

On visionOS, the primary input paradigm uses eyes and hands. With spatial accessories, you can now expand the range of experiences with:

- ✨ **Finer control** for precise interactions
- 🎮 **Button input** for gaming and productivity
- 📳 **Haptic feedback** for immersive experiences

### Supported Spatial Accessories

#### 1. PlayStation VR2 Sense Controller
- **Ideal for:** Gaming applications
- **Features:**
  - Buttons, joystick, and trigger
  - System navigation with standard gestures (tap)
  - Full spatial tracking for sports and action games
- **Example:** Pickle Pro by Resolution Games

#### 2. Logitech Muse
- **Ideal for:** Productivity and creativity apps
- **Features:**
  - Force sensors on tip and side button
  - Variable input levels
  - Powerful haptic feedback
  - High precision for detailed work

### Key Capabilities
- ✅ Works in both **full space** and **shared space** apps
- ✅ Position and rotation tracking via Vision Pro cameras + accessory sensors
- ✅ Tactile haptic feedback for increased immersion

## Building the Sculpting App

### Step 1: Project Setup

#### Configure Xcode Project

1. **Add Spatial Game Controller Support**
   ```
   Info.plist → Capabilities → Spatial Gamepad ✓
   ```

2. **Set Accessory Tracking Usage Description**
   ```xml
   <key>NSAccessorySetupKitSupports</key>
   <array>
       <string>game-controller</string>
   </array>
   <key>NSAccessoryUsageDescription</key>
   <string>Tracking accessory movements to carve into virtual clay</string>
   ```

> **Note:** Users will see this description in a permission popup when they first connect an accessory.

---

### Step 2: Connect to Spatial Accessories

#### Discover Connections
Spatial accessories require active connections to transmit inertial sensor data.

```swift
// Listen for stylus connections
NotificationCenter.default.addObserver(
    self, 
    selector: #selector(stylusDidConnect),
    name: .GCStylusDidConnect, 
    object: nil
)

@objc func stylusDidConnect(_ notification: Notification) {
    guard let stylus = notification.object as? GCStylus,
          stylus.productCategory == .spatialStylus else { return }
    
    // Stylus is connected and supports spatial tracking
    self.connectedStylus = stylus
}
```

#### Controller Connection
```swift
// For game controllers, use similar pattern
NotificationCenter.default.addObserver(
    self,
    selector: #selector(controllerDidConnect),
    name: .GCControllerDidConnect,
    object: nil
)

@objc func controllerDidConnect(_ notification: Notification) {
    guard let controller = notification.object as? GCController,
          controller.productCategory == .spatialController else { return }
    
    self.connectedController = controller
}
```

> **Important:** Always check the `productCategory` to ensure spatial accessory support.

### Step 3: Display Virtual Content with Anchoring

#### Anchoring Locations

##### PS VR2 Sense Controller
- **aim** - Tip of the controller
- **grip** - Handle position
- **gripSurface** - Surface of the grip

##### Logitech Muse
- **aim** - Tip location only

#### Create an AnchorEntity

```swift
// Create anchoring source from spatial accessory
let anchoringSource = AccessoryAnchoringSource(
    accessory: spatialAccessory,
    location: "aim"  // Target the tip
)

// Create AnchorEntity with tracking mode
let anchorEntity = AnchorEntity(
    anchor: .accessory(anchoringSource),
    trackingMode: .predicted  // Or .continuous for higher accuracy
)

// Add virtual content
let virtualTip = ModelEntity(mesh: .generateSphere(radius: 0.01))
anchorEntity.addChild(virtualTip)
```

#### Tracking Modes

| Mode | Use Case | Characteristics |
|------|----------|----------------|
| **`.predicted`** | Rendering, low-latency interactions | May overshoot on jerky movements |
| **`.continuous`** | High accuracy requirements | Higher latency, no overshoot |

### Step 4: Enable Spatial Tracking

Configure SpatialTrackingSession to get accessory transforms:

```swift
// Add accessory tracking to configuration
var config = SpatialTrackingSession.Configuration()
config.tracking = [.accessory]

// Run the session
let trackingSession = SpatialTrackingSession()
await trackingSession.run(config)

// Now you can get transforms from accessory AnchorEntities
```

### Step 6: Create Reactive Toolbar

Use ARKit's AccessoryAnchor to determine which hand holds the accessory:

```swift
// Helper function to get ARKit anchor from RealityKit entity
func getAccessoryAnchor(from entity: AnchorEntity) -> AccessoryAnchor? {
    let arkitComponent = entity.components[ARKitAnchorComponent.self]
    return arkitComponent?.anchor as? AccessoryAnchor
}

// Position toolbar based on handedness
func positionToolbar() {
    guard let accessoryAnchor = getAccessoryAnchor(from: anchorEntity) else { return }
    
    let offset: SIMD3<Float>
    switch accessoryAnchor.heldChirality {
    case .left:
        offset = [0.1, 0, 0]  // Show on right side
    case .right:
        offset = [-0.1, 0, 0] // Show on left side
    case .none:
        return // Not held, don't show toolbar
    }
    
    toolbar.position = offset
}
```

#### AccessoryAnchor Properties

| Property | Description |
|----------|-------------|
| `heldChirality` | Which hand holds the accessory (.left/.right/.none) |
| `relativeMotion` | Relative movement in space |
| `relativeRotation` | Relative rotational movement |
| `trackingState` | Current tracking quality |

## Direct ARKit Tracking

For custom rendering or apps not using RealityKit:

### Key Steps

1. **Create Accessory from GameController**
```swift
let accessory = Accessory(from: gcController)
```

2. **Configure AccessoryTrackingProvider**
```swift
let provider = AccessoryTrackingProvider()
let config = AccessoryTrackingConfiguration(accessories: [accessory])
```

3. **Handle Connection Changes**
```swift
// Re-run ARKit session when accessories connect/disconnect
session.run(updatedConfiguration)
```

### Update Patterns
- **Stream updates** - For accurate, continuous tracking
- **On-demand prediction** - For interactive user feedback

> **Example:** See ARKit sample app "Tracking accessories in volumetric windows"

## Design Considerations

### 1. Gesture and Controller Input

Enable views to receive both gesture and controller input:

```swift
struct InteractiveView: View {
    var body: some View {
        VStack {
            // Your content
        }
        .onGameControllerButtonInput { button, pressed in
            // Handle controller input
        }
        .receivesEventsInView()  // Also receive gesture events
    }
}
```

> **Note:** When using spatial accessories, spatial event gestures will include chirality information.

### 2. Immersive Mode Options

For full space apps, enhance immersion:

```swift
// Hide home indicator
.persistentSystemOverlays(.hidden)

// Hide upper limbs and accessories
.upperLimbVisibility(.hidden)
```

### 3. Adaptive Support

#### Best Practice: Support Both Hands and Accessories
- ARKit hand tracking is now even faster
- Design for users with and without accessories
- Provide alternative input methods

### 4. App Store Badges

| Badge Type | Use When | Info.plist Key |
|------------|----------|----------------|
| **"Spatial game controller support"** | App supports but doesn't require | `GCSupportsSpatialGamepad` |
| **"Spatial game controller required"** | App requires spatial controller | `GCRequiresSpatialGamepad` |
